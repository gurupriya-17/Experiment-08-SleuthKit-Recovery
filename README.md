# Experiment 8: Recover Deleted Files Using Sleuth Kit

## Aim
To recover deleted files from a forensic disk image using Sleuth Kit.

## Tool Used
- Sleuth Kit

## Procedure
1. Open a terminal in a supported forensic Linux environment.
2. Identify the authorized disk image to be examined.
3. Use Sleuth Kit tools to analyze the file system.
4. Identify the relevant file system and deleted-file entries.
5. Examine the metadata of the deleted files.
6. Recover the required file, if its contents are available, using the appropriate Sleuth Kit commands.
7. Save the recovered file to a separate output directory.
8. Verify and document the recovery results.
